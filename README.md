# AQI Index Analysis Dashboard

## Project Overview

The **AQI Index Analysis Dashboard** is a Power BI project designed to analyze and visualize **Air Quality Index (AQI)** data across India. It provides interactive insights into pollution levels, top polluted cities, state-wise AQI distribution, and monthly trends.


---

## Objectives

- Analyze AQI levels across Indian states and cities  
- Identify the **Top 10 cities with highest AQI**  
- Categorize air quality based on standard AQI levels  
- Study **month-wise AQI trends**  
- Enable dynamic filtering using slicers  

---

## Tools & Technologies

- **Microsoft Power BI**
- **Power Query Editor**
- **DAX (Data Analysis Expressions)**
- **Dataset**: Government-compliant AQI data structure (CPCB inspired)

---

## Dashboard Features

### Key KPIs
- Average AQI  
- Primary Pollutant  
- AQI Category  

### Visuals
- Top 10 Cities with Highest AQI (Bar Chart)  
- AQI by State (Map Visualization)  
- Month-wise Average AQI Trend (Area Chart)  
- AQI Levels Legend  

### Filters
- Year  
- State  
- Area  

---

##  AQI Categories

| AQI Range | Category |
|---------  |--------- |
| 0–50      | Good |
| 51–100    | Moderate |
| 101–200   | Poor |
| 201–300   | Unhealthy |
| 301–400   | Hazardous |
| 401+      | Chernobyl |

---

## Key Insights

- Metro cities show consistently higher AQI levels  
- Winter months have the worst air quality  
- Certain states frequently fall under Poor to Unhealthy categories  
- Primary pollutants drive AQI spikes in urban areas
